Architecture

 GreenAI Digital app / cloud ──HTTPS──▶  Raspberry Pi 5  (planning, SLAM, vision, REST API, schedule)
                                              │ UART 115200
                                              ▼
                              ESP32-S3 (real-time safety + motors)
   LiDAR(USB) ─▶ Pi        cliff ToF x4 ─▶ MCU      wheels / fan / brushes ◀─ MCU
   Camera(CSI) ─▶ Pi       bumpers x3  ─▶ MCU       watchdog: Pi silent 500 ms ⇒ motors off
   IMU(I2C) ───▶ Pi        current sense ▶ MCU      dock IR beacon ─▶ MCU ─▶ Pi (docking)
